# 🤝 Contributing to DevConnect API

Thank you for contributing.

This project is designed to help beginners learn real-world backend development through practical contributions.

---

## 📌 Before You Start

Please:

* Read the README carefully
* Check existing issues before creating a new one
* Be respectful during discussions and reviews

---

## 🚀 Contribution Workflow

### 1. Fork the Repository

Click the **Fork** button on GitHub.

---

### 2. Clone Your Fork

```bash
git clone <your-fork-url>
```

---

### 3. Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

Example:

```bash
git checkout -b feature/add-health-endpoint
```

---

### 4. Make Your Changes

Work only on the assigned issue.

Keep changes:

* small
* focused
* readable

---

### 5. Commit Your Changes

```bash
git commit -m "Added health endpoint"
```

---

### 6. Push Changes

```bash
git push origin feature/your-feature-name
```

---

### 7. Create Pull Request

Open a Pull Request with:

* clear title
* proper description
* issue reference if possible

---

## 📌 Contribution Rules

* Do not submit large unrelated changes
* Write clean and understandable code
* Ask questions if stuck
* Respect review feedback

---

## 🧠 Beginner Notes

You are not expected to know everything.

This project exists for learning through:

* contribution
* feedback
* iteration

Mistakes are normal.

---

## 📬 Need Help?

Open an issue or ask in discussions.

Happy building 🚀
