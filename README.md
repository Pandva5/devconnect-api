## ⚡ How to Start (First Contribution Path)

### Step 1 — Pick a Project

Go to: 👉 **PROJECTS.md**
Choose a project based on your skill level.

---

### Step 2 — Find a Beginner Task

Look for issues labeled:

* `good-first-issue`
* `beginner-friendly`

---

### Step 3 — Comment on the Issue

Example:

> “I want to work on this issue”

Wait for assignment (or proceed if open).

---

### Step 4 — Work & Submit PR

* Fork the repo
* Create a new branch
* Make changes
* Submit a Pull Request

---

### Step 5 — Get Feedback & Improve

You’ll receive review comments.
Fix them → Learn → Merge.
